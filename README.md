### 🛡️ Featured project: [SOC Home Lab](https://github.com/Abdullah0415/SOC-Home-Lab)

A hands-on detection engineering lab with a Wazuh SIEM, a Windows 11 endpoint running Sysmon, and a Kali Linux attacker.

- **Custom Wazuh detection rules** mapped to MITRE ATT&CK, each proven by reproducing the real attack
- **Detections** for brute force (SSH and RDP), persistence, lateral movement, tool transfer, file tampering and log clearing
- **Automated response** with Wazuh Active Response, including where it fails and why
- **Investigation playbooks**, false-positive tuning with negative tests, and documented visibility gaps
- **Root-cause analysis** of a recurring endpoint crash with the Event Log and WinDbg
