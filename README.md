### 🛡️ Featured project: [SOC Home Lab](https://github.com/Abdullah0415/SOC-Home-Lab)

A hands-on detection engineering lab with a Wazuh SIEM, a Windows 11 endpoint running Sysmon, and a Kali Linux attacker. **Complete: 18 exercises.**

- **23 custom Wazuh detection rules** mapped to MITRE ATT&CK, each proven by reproducing the real attack, including a level 15 incident correlation rule
- **Detections** for brute force (SSH and RDP), persistence, lateral movement, tool transfer, PowerShell obfuscation, Linux privilege escalation (auditd), file tampering and log clearing
- **A full intrusion investigation** with a written incident report (IR-01)
- **Alert tuning** measured over before/after windows, with a positive and a negative test for every suppression
- **Automated response** with Wazuh Active Response, including where it fails and why
- **8 investigation playbooks**, documented visibility gaps, and root-cause analysis of an endpoint crash with WinDbg
